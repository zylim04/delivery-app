What is CV RMSE?

Average RMSE across 5 validation folds during tuning. Lower means better generalisation.

Why 5-fold CV?

Uses all training data for validation while preventing overfitting to any single split.

CV vs Test RMSE

CV RMSE comes from training data only. Test RMSE is the final honest evaluation on unseen data.

What is SHAP?

SHAP values measure the average contribution of each feature to the model's prediction across all training samples. Higher SHAP value = stronger impact on delivery time prediction.

{% endif %}
SHAP Feature Importance — LightGBM

Mean absolute SHAP values computed on 500 training samples.

SHAP Key Findings
  • 01 delivery_person_ratings — rider rating has the strongest impact; higher-rated riders deliver faster.
  • 02 delivery_person_age — rider age significantly influences delivery speed.
  • 03 road_traffic_density_Low — low traffic strongly reduces delivery time.
  • 04 distance_km — longer distances directly increase delivery time.
  • 05 vehicle_condition — vehicle condition affects rider reliability.
Game-theory based
About SHAP

SHAP (SHapley Additive exPlanations) is a game-theory based method for explaining ML predictions.

Unlike basic feature importance, SHAP accounts for feature interactions and gives mathematically rigorous explanations.

Values are mean absolute SHAP values — direction of impact is ignored, only magnitude is shown.
