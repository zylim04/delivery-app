About This Project

📌 Project Overview

This system predicts food delivery time using machine learning. It was developed as a Final Year Project (FYP) using a dataset of 42,592 real delivery records from the Zomato platform.

The system uses XGBoost, a gradient boosting ensemble model tuned with RandomizedSearchCV and 5-fold cross-validation to achieve a Test R² of 0.8393 and Test RMSE of 3.78 minutes.

🎯 Research Objectives
  1. Identify key factors that influence food delivery time using feature importance analysis.
  2. Build a leakage-free preprocessing pipeline for reliable model training.
  3. Compare multiple ML models and select the best performing model.
  4. Deploy the best model as a web-based prediction system.
🔬 Methodology
EDA → Cleaning → Feature Engineering → Modelling → Evaluation → Deployment

The pipeline follows CRISP-DM methodology with strict separation of training and test data to prevent data leakage.

🛠 Tools Used
  • ML XGBoost, Random Forest, Decision Tree, Linear Regression
  • Tuning RandomizedSearchCV, Optuna
  • Pipeline scikit-learn, pandas, numpy
  • Web Flask, Bootstrap 5, Jinja2
  • Notebook Jupyter Notebook, VS Code
📂 Dataset
  • Source: Zomato Delivery Dataset
  • Total rows: 45,584
  • After cleaning: 42,592
  • Features: 20 input variables
  • Target: time_taken_min
  • Train split: 80% (34,073 rows)
  • Test split: 20% (8,519 rows)
🏆 Best Model
  • Model: XGBoost
  • Tuning: RandomizedSearchCV
  • CV: 5-fold
  • Test RMSE: 3.7771 min
  • Test R²: 0.8393
  • Train-Test Gap: 0.0503

Target Users

This system is designed for stakeholders across the food delivery ecosystem, each benefiting from different features of the platform.

Platform Operators

Track delivery performance trends and identify common delay patterns using the Analytics Dashboard and Delay Trend Insights pages.

Operations Team

Use prediction results and dashboard insights to optimise delivery operations and resource allocation.

Customers

View estimated delivery time before ordering, improving transparency and customer satisfaction.

Riders

Use estimated delivery time as a guide for planning routes and managing multiple orders.

Restaurants

Plan food preparation timing based on estimated delivery time, ensuring food quality upon arrival.
