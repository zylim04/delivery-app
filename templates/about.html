About This Project

Project Overview

This system predicts food delivery time using machine learning. It was developed as a Final Year Project (FYP) using a dataset of 42,592 real delivery records from the Zomato platform.

The system uses LightGBM, a gradient boosting ensemble model tuned with Optuna Bayesian optimisation and 5-fold cross-validation to achieve a Test R² of 0.8393 and Test RMSE of 3.78 minutes.

Research Objectives
  • 01 To identify and rank the top factors affecting food delivery time in urban areas using SHAP feature importance analysis.
  • 02 To preprocess historical delivery data by handling missing values, removing structural errors, and engineering relevant features to produce a clean dataset.
  • 03 To develop, tune, and compare multiple machine learning models and deploy the best-performing model, selected based on predictive accuracy and generalisation.
  • 04 To develop an interactive web-based analytical dashboard that visualises delivery time predictions and key delay trend insights across traffic, weather, city, festival, and time dimensions.

Target Users

This system is designed for stakeholders across the food delivery ecosystem, each benefiting from different features of the platform.

Platform Operators

Track delivery performance trends and identify common delay patterns using the Analytics Dashboard.

Operations Team

Use prediction results and dashboard insights to optimise delivery operations and resource allocation.

Customers

View estimated delivery time before ordering, improving transparency and customer satisfaction.

Riders

Use estimated delivery time as a guide for planning routes and managing multiple orders.

Restaurants

Plan food preparation timing based on estimated delivery time, ensuring food quality upon arrival.
